# Aktenvorlagen – Auswahl beim Schreiben

Die [Runablage](../references/PAKETABLAGE_UND_VORLAGEN.md) definiert die Struktur. Diese Dateien werden beim Erstellen des jeweiligen Artefakts verwendet; kein Pflichtlesen aller Vorlagen am Runstart.

- Paket eröffnen/Status pflegen: [Paketindex](PAKETAKTE/00_PAKET.md).
- Dauerhafte Entscheidung dokumentieren, falls erforderlich: [Entscheidungen](PAKETAKTE/01_ENTSCHEIDUNGEN.md).
- Tatsächlichen Auftrag sichern: [Original-Prompt-Hülle](RUN/00_PROMPT_ORIGINAL.md).
- Umsetzung, Korrektur oder unabhängiges Review berichten: [Runreport](RUN/01_REPORT.md).
- Test-/Wire-/Build-/Migrationsbelege zuordnen: [Evidenzindex](RUN/EVIDENCE/INDEX.md).

Auftragsschablonen stehen direkt bei den [Umsetzungs-](../../voice-stt-client-v2-umsetzen/SKILL.md) und [Abnahmeskills](../../voice-stt-client-v2-abnehmen/SKILL.md). Wiederkehrende Regeln sind dort verlinkt. Keine ausgefüllte Vorlage behauptet einen bereits ausgeführten Run oder eine Freigabe.
